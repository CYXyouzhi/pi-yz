## 一个需要说清的口径问题（对自己的批评）

`space-rework/README.md` 与 `space-rework/gates.txt` 里写的「空闲态消息区 91%」，
实际是 **口径 A**（屏幕顶到输入区上沿，**含标题栏与状态栏**），不是纯消息区。

这个混用是我上一轮留下的：当时 `measure.py` 按「最长内容段」切分，而标题栏图标行
与消息区之间没有空白分隔，两者被算成同一段，输出 `y0-876 ≈ 584 逻辑 = 91%`
（注意起点是 `y0`）。本轮把它拆成两个口径分别报告，并补了旧版的同口径复测值。

以后引用消息区比例时，**必须写明是哪个口径**，否则 91% 和 81% 会看起来像互相矛盾。
