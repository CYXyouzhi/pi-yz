## 这轮修掉的两个真实缺陷

| 缺陷 | 现象 | 修法 |
|---|---|---|
| 运行中点状态条打不开浮层 | 空闲时点一下就能开；**跑起来之后连点三四次都没反应**，反而把消息列表滑动了。原因是会话页每秒 `setState` 重建一次（秒表挂在 `_syncUsagePolling` 里），按下与抬起之间那一帧把手势丢了 | 把秒表**下沉到 ActivityBar 自己**（StatefulWidget + 自己的 Timer，只重建这一条），会话页不再每秒重建。修完实测 `11-sheet-running-after-fix.png`：运行中一点即开 |
| 空会话没有入口进实时活动视图 | 状态条在「没有任何活动」时直接 `SizedBox.shrink()`，于是新会话里既看不到「还没有活动」，也没有任何地方能点开浮层 —— 合同④的空态等于没有 | 改成只有「压根没打开会话」时才隐藏；空会话照样显示状态条（写「还没有活动」），点开就是空态浮层 |

## 顺带改准的两个细节

- **「本轮 N 次工具调用」原来统计的是整个会话**（实测一个跑过 10 次工具调用的老会话，空闲时状态条写「本轮 10 次工具调用」，读起来像刚跑完）。改成只数**最后一条用户消息之后**那一段；时间线本身仍然是全量（往上滚能看到历史）。
- **`ask_user_question` 在时间线上摘要显示成 `—`** —— 它的参数是结构化的 `questions: [{header, ...}]`，不在常见参数名表里。补了从 `questions` / `options` 里挑人话的兜底，现在显示「水果偏好」。

## 复现步骤（MuMu 上自己再看一遍）

1. 打开一个会话：标题栏下方出现状态条。开一个刚建的空会话，它写「还没有活动 agent 空闲中」；点开浮层是「还没有活动」的空态。
2. 发一句会让 pi 多跑几步的话（例如「依次 bash sleep 10 三次，最后回复 DONE」）。
3. 跑起来时状态条写「正在跑 + 当前动作 + 已跑 N 秒 + N tok/s」，秒数自己会走（不用切页面）。
4. **运行中**点状态条 → 浮层打开；停 2 秒再看，新出现的工具调用或回复会自己排到最上面。
5. 让它改一个文件（例如「用 write 工具建 pi-activity-test.txt」）→ 时间线上出现 `write 文件名 ✓`，统计行出现「1 个文件」。
6. 让它提问（例如「用 ask_user_question 问我最爱吃的水果」）→ 状态条变「● 等你确认」（橙点），浮层统计行写「等你确认 1 项」。
7. 回答完再等一会儿 → 状态条回「空闲 · 本轮 N 次工具调用」，浮层顶部写「本轮已结束 · … · 用时 N 秒」。
